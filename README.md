# Password-Manager

A secure and modern Password Manager Android app built using **Jetpack Compose**, **Jetpack Security**, and **Room**. It allows users to store, edit, and manage passwords locally with encryption and PIN-based authentication.

---

## ✨ Features

- ✅ Add, view, edit, and delete saved passwords
- 🔐 Secure local storage using AES-256 encryption (via Jetpack Security)
- 🔏 4-digit PIN authentication on app launch
- 📋 Password generator (with refresh icon)
- 🧠 Password strength meter (optional)
- 📱 Material 3 UI built with Jetpack Compose
- 🧩 Bottom sheet UI for password add/edit
- ⚠️ Input validation & error handling
